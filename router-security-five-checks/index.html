공유기 보안 설정 5가지

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일

공유기는 집 안의 PC, 스마트폰, 태블릿이 인터넷으로 나가는 문이에요. KISA 보호나라는 2024년 11월 무선공유기를 안전하게 쓰기 위한 수칙을 카드뉴스로 안내했어요.

왜 점검해야 하나요

보안이 약한 공유기는 DDoS 공격에 봇넷으로 악용되거나, 네트워크 설정이 몰래 바뀌어 악성 사이트로 유도되는 금전 피해로 이어진 사례가 있다고 해요.

점검 5가지

  1. 관리자 비밀번호를 바꿔요. 구매할 때 설정된 초기 ID와 비밀번호는 웹 검색만으로 쉽게 알 수 있어서 누구나 접속할 수 있어요. 처음 쓸 때 꼭 바꾸고, 영문 대소문자, 숫자, 특수문자를 섞어 8자리 이상으로 주기적으로 바꾸라고 안내해요.
  2. 필요한 기능만 켜요. 원격접속 관리나 UPnP 같은 기능은 출고 때 켜진 채로 판매되기도 해요. 쓰지 않는 기능이 켜져 있으면 외부 접근과 해킹의 통로가 될 수 있어서 꺼야 해요.
  3. 무선 네트워크 설정을 확인해요. 신호가 아랫집이나 옆 건물까지 닿을 수 있으므로 강력한 보안 설정이 필요해요. 안내는 SSID 숨김, 암호 방식을 WPA2 계열로 설정하기, 사전에 등록한 기기만 이용하게 하기를 권해요.
  4. 펌웨어를 업데이트해요. 취약점이 있으면 침입자가 공유기를 마음대로 조작할 수 있어서, 최신 펌웨어가 있는지 주기적으로 확인해요.
  5. 연결된 기기 목록을 봐요. 모르는 기기가 붙어 있지 않은지 확인하고, 쓰지 않는 기기는 연결을 해제해요. MAC 인증으로 등록한 기기만 쓰게 하는 설정도 권해요.

기본 관리자 비밀번호는 다른 공지에도 나와요

2025년 6월 KISA 공지는 주로 기업을 대상으로 하지만, NAS가 랜섬웨어에 감염된 사례로 공장 출하 때 설정된 기본 관리자 비밀번호를 그대로 쓰거나 보안 업데이트를 하지 않은 경우를 들어요. 대응 방안에도 최초 설치 때 기본 관리자 비밀번호를 반드시 바꾸라는 항목이 있어요. 공유기를 포함한 네트워크 장비는 자동 업데이트를 켜 최신 펌웨어를 유지하라고 권하고, 불가피하면 비밀번호 관리와 보안 업데이트를 철저히 하라고 해요.

더 알아볼 곳

보호나라의 내PC돌보미 서비스를 신청하면 쓰고 있는 공유기의 취약점 점검도 받을 수 있다고 안내해요. 안내문에는 점검 주기가 몇 개월이라는 숫자는 없고, 비밀번호 변경, 펌웨어 확인, 연결 기기 목록 확인을 모두 주기적으로 하라고만 되어 있어요.

안 하면 어떻게 되나: 항목별 정리

점검 항목 방치했을 때 안내된 위험
관리자 비밀번호 초기 ID와 비밀번호는 웹 검색만으로 알 수 있어 누구나 접속할 수 있어요
불필요한 기능(원격접속 관리, UPnP) 출고 때 켜진 채라서 외부 접근과 해킹의 통로가 될 수 있어요
무선 설정 신호가 아랫집이나 옆 건물까지 닿아 공유기에 접근할 수 있어요
펌웨어 취약점을 이용해 침입자가 공유기를 마음대로 조작할 수 있어요
연결 기기 모르는 기기가 붙어 있어도 알아차리기 어려워요

처음 한 번 점검하는 순서

공유기 관리 화면에 들어가서 아래 순서로 한 번 훑어보면 5가지를 모두 확인할 수 있어요(순서는 정리 요령이고, 메뉴 이름은 제조사마다 달라요).

  1. 관리자 비밀번호가 초기값인지 확인하고 바꿔요. 영문 대소문자, 숫자, 특수문자를 섞어 8자리 이상으로 해요.
  2. 원격접속 관리와 UPnP를 쓰지 않는다면 꺼요.
  3. 무선 설정에서 암호 방식, SSID 숨김, 등록 기기만 허용하는 설정을 확인해요.
  4. 펌웨어 항목에서 최신 버전이 있는지 보고 업데이트해요.
  5. 연결된 기기 목록에서 모르는 기기가 있으면 연결을 해제해요.

공유기는 집뿐 아니라 식당, 카페에서도 쓰이는 장치라는 점을 KISA 카드뉴스가 언급해요. 가게나 사무실에서 공유기를 운영한다면 같은 점검을 적용해야 해요.

핵심 정리

  • 초기 ID와 비밀번호는 반드시 바꿔요.
  • 원격접속 같은 불필요한 기능은 꺼요.
  • 무선 설정과 펌웨어를 확인해요.
  • 연결된 기기 목록에서 모르는 기기를 찾아봐요.
